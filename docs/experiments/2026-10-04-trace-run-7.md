Replayed per chapter (`--upto N-1 --draft` with the accepted chapter standing in for the draft):

| draft | what the line editor and story editor would have been given |
|---|---|
| ch 3 | the refrain as a note, x3; the two-hander run warns |
| ch 4 | the refrain x3 and barrel-head x3 as notes; the two-hander run warns |
| ch 5 | the refrain warns at x4 |

The ch 5 line editor kept the refrain as a callback. With this report, it would have been
counting its fourth use.

- **Calibration:** run #7 only. The signature rule is ported unchanged from skilled-writer, where
  it was tuned on runs #5 and #6.
- **Motif threshold:** a `warn` needs 3 chapters and 4 uses, the shape of both refrains the
  judges named.
- **Two-handers:** the count is the floor skilled-writer used: a turn with no name beside it
  counts nobody. It reads 13 of 16 here, while the clerk's scene log marks only 4 of 24 scenes as
  two-handers. The reader's complaint sides with the floor: two named voices carried the talk,
  even with a crowd standing by. The report says it is a floor.
