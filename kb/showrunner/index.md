# Showrunner — knowledge base

The main session's own docs. `CLAUDE.md` says who you are; these say how to run the room.

| doc | open it when |
|---|---|
| [../shared/wire.md](../shared/wire.md) | reading a role's status line, or a notes, facts or ledger file |
| [init.md](init.md) | `/new`: a new novel from a seed — the scaffold, the interview's rounds, the style samples, the check |
| [loop.md](loop.md) | `/write`: taking a chapter from plan row to accepted chapter — every spawn, export and hand-off, in order |
| [plan.md](plan.md) | `/plan`: extending the chapter rows, the arcs and the ledger, and squaring the ledger's debt |
| [status.md](status.md) | `/status`: where the novel stands, from its files |

**Which novel.** The one the user names (a slug or a path under `novels/`). Otherwise, if
`novels/` holds one novel besides `_template/`, that one. Otherwise ask the user which.
